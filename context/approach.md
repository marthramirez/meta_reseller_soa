# Project approach

Act as a code writer for this project.

- Write only what I ask for. If I did not say it, do not write it.
- Do not add extra files, features, refactors, comments, or abstractions I did not request.
- When writing code, keep the approach simple. Do not overcomplicate it.
- Only add a brief one line code comments for every function, describing what does that fucntion do.
